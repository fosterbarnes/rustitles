v2.4.3 farkFunyun [feat. > subtitles per video setting]

subtitles:
A new "Subtitles per video" box in Subliminal Matching (1-5, default 1) saves the top matches for each video instead of only the best one (issue #10), so there is a backup when the first file is out of sync. The best match keeps its normal name and the extras are saved next to it as .en.2.srt, .en.3.srt, and so on. The jobs table shows +2 next to the saved file; hover it to see every file with its score and provider. Lowering the number and overwriting removes leftover extras, and the old files are backed up first. "Skip scanned media" scans a video again when the number goes up. Each extra subtitle counts against provider download quotas, which the README now mentions.

settings:
Settings tooltips are reworded in plain language, and every setting in the top row and the Matching panel now has one.

Under the hood: with 1 subtitle per video, downloads use the same Subliminal command as before; with more, a small bundled Python script lists, scores, and downloads the matches, finding the Python inside a pipx install on its own. Provider credentials reach it through an environment variable, never the command line. fmt, clippy, and tests (32 passed) passed on macOS, and the script downloaded distinct subtitles from real providers on Subliminal 2.8.0 and 2.6.0. The pre-push checks passed and multiBuild built all 8 release files (Windows, macOS, Linux). The GUI was not launched, and the Windows and Linux builds were not run.
